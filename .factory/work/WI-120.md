## The problem

**The front page of a public repository still describes the product the owner
replaced.**

Two lines carry it:

- `README.md:3` — `**An agent-native control panel and personal software
factory.**`
- `package.json:7` — `"description": "Personal OS — agent-native control panel
and personal software factory."`

GitHub's page title, its meta description and its social preview are all
derived from these two, so the sentence is what the repository says it is to
anyone who arrives at it.

**And the sentence states three of the product's own exclusions.** The product
record lists what this product is not — `docs/strategy.md:37`: not a chat
home, not a workflow editor, not an inference engine, not a plugin
marketplace. A "control panel" is coordination, "talk to agents, run group
conversations" is a chat home, and "software factory" is the half the owner
said is a part of the product rather than the whole of it.

**The line that replaces it is the product's own sentence.**
`docs/strategy.md:20` reads:

> **Personal OS is an environment that one person's agents operate and
> extend.**

so the front page reads:

> **The environment one person's agents operate and extend.**

and the manifest's description reads:

> `Personal OS — the environment one person's agents operate and extend.`

**This is the only artefact already in the world.** The repository was
published on 2026-10-21 under MIT, at `74e00cb`, and it is served to anyone
who knows the address: zero stars, zero forks, and nobody has found it yet.
Everything else this factory does is still a branch. This is not.

## Why now

The window in which the correction is invisible to the public is the window in
which the repository has no readers. That window is the whole reason the owner
