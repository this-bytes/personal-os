# WI-147 — The contract publishes the event, not the approval it carries

**Owner:** the contract lane — the session that owns `CONTRACTS.md` while its
slices are in flight.
**Verifier:** Probe, who found the gap; the lead re-measured the fix.
**State:** accepted
**Branch:** none — the fix landed on `main`.
**Base:** `cba153a` (the tip at which the gap was measured)

## Problem

**A client could not read the payload of an event the contract publishes.**

At `cba153a` the contract published `approval.decided` in two places, and both
named the field without naming the shape:

- the vocabulary row — `| approval.decided | { approval } |`
- the AG-UI counterpart — `| approval.decided | CUSTOM named approval.decided |`

The projection passes the object through unchanged
(`apps/server/src/api/agui-protocol.ts:713-715`,
`value: { approval: event.approval }`), so both carried the same `Approval` —
and the contract published no `Approval` shape. `WaitingItem`,
`ApprovalEvidence`, `ExecutionEvidence`, `ToolCallEvidence` and
`ArtifactEvidence` were all declared; the approval was not. **A client that
subscribed to `approval.decided` had to read the payload's fields from the
code, not from the contract.**

## Scope and compatibility

**Owned paths**

- `CONTRACTS.md` — publish the approval's shape beside the event that carries
  it, and name that shape in the vocabulary row and in the AG-UI counterpart.
- `packages/contracts/src/approvals.ts` — cited, not edited.

**Compatibility.** No published shape changed; this published one that already
existed. A client that already read the payload from the package is
unaffected.

## Acceptance criteria

- [x] `CONTRACTS.md` publishes the `Approval` shape, with its fields.
- [x] The vocabulary row and the AG-UI counterpart name that shape, so a client
      can read the payload's fields from the contract alone.
- [x] The citation binds to the claim — the shape is published member for
      member, and the source of the shape is cited.
- [x] The applicable gates pass, and nothing is weakened.

## Not in scope

- Changing the payload, the event, or the route.
- The other shapes the contract already publishes.
