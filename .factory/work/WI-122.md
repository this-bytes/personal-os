## The finding

**Two contract gates can both be green while the contract has silently stopped naming the
route.** Probe found this while verifying WI-086, and it is the lead's job to keep it:

- **The pointer gate** asks whether every citation in the contract points at **code**. It
  proved `CONTRACTS.md:1480`'s citation of `api/approvals.ts:37` pointed at code — **after
  Probe pushed one line of ordinary code above the route, the route moved to `:38` and the
  contract still said `:37`. The pointer gate exited 0: 126 checked, 0 failures.**
- **The status gate** asks whether a claim's implementation note is **somewhere in a file**.
  It does not ask whether the note's **line numbers** are right, so **it also exited 0**.

**So the note had stopped naming the route, and nothing noticed.** That is the gap this item
closes. **A pointer can hold code and still not carry its claim** — and here two gates that
watch the contract every day could not see it.
