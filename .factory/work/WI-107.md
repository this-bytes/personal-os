## Problem

`CONTRACTS.md` cites the code by line number all over its prose —
`apps/server/src/api/helpers.ts:76`, `apps/server/src/modules/resources/service.ts:525`
and so on. **Those citations go stale every time a nearby line changes, and
nobody notices until somebody reads one and finds the wrong code there.** Three
work items have already been spent correcting them by hand — WI-034, WI-103, and
the publication that is landing now — which makes this a defect class and not
three coincidences.

Expected behaviour: a gate that checks every citation in `CONTRACTS.md` against
the tree, the way `scripts/verify-contract-status.ts` checks the
implementation-status notes against the tree. The gate **never edits the
contract** — a stale citation is a human decision, and `CONTRACTS.md` is one
file that several items hold at once.

## Why now

The gate lands **after** the corrections that are in flight, so it is the
mechanism that keeps them corrected. A correction that is made by hand and never
checked is a correction that goes stale again in a month.

## Acceptance criteria

- [ ] `scripts/verify-contract-pointers.ts` finds every citation of a TypeScript
      file in `CONTRACTS.md` — `path:line` and `path:line-line`, written in
      backticks — and leaves the citations of files that are not TypeScript
      alone.
- [ ] A citation fails when it names no path from the repository root, when the
      file is not in the tree, when the line is out of range, when a range runs
      backwards, and when the cited line holds no code — empty, a comment, or no
      letter at all.
- [ ] For a range, the rule applies to every line in the range.
- [ ] The gate fails with one line per finding, naming the contract's own line,
      the citation and the reason; then a count; then a closing line.
- [ ] The gate never edits `CONTRACTS.md`, and `CONTRACTS.md` is not edited.
- [ ] A test file proves the gate **fails** on bad input: a good pointer, a
      pointer past the end of the file, a pointer at a comment, a pointer at a
      blank line, a pointer with no path, a pointer to a file that is not in the
      tree, and a range that holds a blank line.
- [ ] The gate is a job of its own in `.github/workflows/ci.yml`, with the same
      reasoning about `npm ci --ignore-scripts` and the lockfile, and the same
      timeout as the contract-status job.
