# WI-056 — The worker's context budget, and the tool eligibility chain

**Owner:** Cog
**Verifier:** Probe
**State:** intake — funded and numbered, and **not dispatched**. It follows
WI-055, and it is a worker concern rather than a contract one.
**Opened:** 2026-10-21 by the strategy session, from the owner's answer that
the harness patterns split by boundary
**Numbered:** 2026-10-21 — WI-046 through WI-061, taken by the session that owns
the number space.

## The owner's answer, and the gap it names

**The owner's answer, 2026-10-21: split by boundary. Client-visible patterns in
the interaction contract; worker internals as their own item.**

The gap: two of the harness's behaviours are entirely inside the worker, and
Personal OS has neither.

**The context budget.** A turn's context is unbounded today: history is
written while it streams, nothing measures it, and nothing is archived. The
harness budgets it arithmetically — with window `C`, output cap `O`, reserve
`R` and safety margin `S`, `C − O − S ≥ R` selects the effective output
`O_eff = min(O, R)`; the input limit is
`L = max(1, min(floor(0.95 × C), C − R, C − O_eff − S))`; and the compaction
threshold is `T = min(L, max(1, C − min(2 × R, floor(C / 4))))`. A result
archiver then plans before it mutates, keeps recent turns protected, and only
archives when the tokens or the bytes actually fall and the result stays
re-readable.

**The tool eligibility chain.** Before a tool starts, the chain checks
duplicate tool-call ids in the turn, resolves a delegated call's _real_
execution target, passes safety and plugin pre-checks, tool policy and
extension hooks, and only then takes the permission decision — so permission is
decided against reality and not against a claim about what is being called.
Personal OS's guards live in the routing; the permission decision does not
re-check the target or the turn's liveness.

## Acceptance criteria

- [ ] **A turn's context is budgeted from the published arithmetic**, per
      adapter, and the budget is visible in the execution's record.
- [ ] **The archiver plans before it mutates**, keeps recent turns protected,
      and archives only when the tokens or the bytes actually fall and the
      result stays re-readable. A read of an archived result still returns the
      answer.
- [ ] **The eligibility chain is in the order the harness publishes it**, and
      the permission decision is taken against the resolved target.
- [ ] **A duplicate tool-call id in a turn is refused**, and a permission that
      returns after the turn ended cannot revive it.
- [ ] **The budget is not a contract change.** It is the worker's own business,
      and nothing a client can observe changes shape.

## Not in scope

- **Anything client-visible.** The published patterns are WI-055, and this item
  is the other half of the split.
- **A model loop, a sandbox, or a provider SDK.** The harness has all three and
  Personal OS takes none of them.
- **The context compaction lifecycle.** That is named in the published
  commit protocol (WI-052) and lands with WI-055; this item budgets and
  archives, and it does not change the commit's shape.

## Notes

**The risk this item carries is the one ADR 0009 names.** Porting harness
patterns could pull in a model loop or a sandbox by accident, which is the
"another agent harness" failure mode. The line: no port crosses into provider
or inference code, and the arithmetic above is copied as a _specification_ and
reimplemented against our own types.
