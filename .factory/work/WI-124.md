# WI-124 — The mode's meaning is settled: `manual` does not gate delegation

**Numbered:** 2026-10-22, as WI-122. **WI-124** is the number this item took.

free number is WI-122", and it was renumbered before it landed: **the peer

## The decision

The owner was asked what `manual` means, because the contract said the meaning
of the modes was the owner's decision and it was not settled. The owner
answered:

> **Leave it: `manual` does not gate delegation, and that is stated plainly in
> the product's own words.**

So the mode stays what it has been — resolved, readable, and consulted by
nobody — and the product says so plainly instead of leaving it open.

## What this item does

It changes no behaviour and adds no enforcement. It makes five things say the
same true thing.

1. **`PRODUCT.md`** — the paragraph that says what `autonomous` is to mean, and
   that the question is not settled, becomes a statement of the fact: the mode
   is resolved, readable and enforced nowhere; `manual` does not gate
   delegation; the mode is a description and not a control.
2. **`CONTRACTS.md`** — the same paragraph in the mode section, and the clause
   that says what the mode is to mean is still the owner's decision. Both go,
   because the decision has been made.
3. **`apps/server/src/modules/workspaces/service.ts`** — the comment beside the
   write that says the mode is enforced nowhere and its meaning is still the
   owner's decision.
4. **`.factory/work/WI-082.md`** — decision 4's second sentence said `manual`
   means the agent may not begin work on its own initiative. That is the
   reading the owner has now declined. The first half of decision 4 — that
   `manual` must not regress today, that owner-directed turns, owner-approved
   automation runs and triggered automations keep working — is settled and
   stays.
5. **The attack suite** — WI-085's case named _stops the agent beginning work
   on its own initiative under manual_ asserted that a delegation under
   `manual` produces no reply. That assertion encodes the reading the owner
   has declined. The case is re-stated to assert the truth: under `manual` a
   delegation still produces a reply, because nothing reads the mode. The
   control case — a delegation under a mode that permits it — stays, so the
   pair says the mode makes no difference.

## The proof

The mode was never a gate, so the re-stated case passes against the code that
is already there: removing the mode from the fixture changes nothing, because
the mode was never read. That is the point of the case. A future change that
makes `manual` gate delegation turns it red, and that change is a contract
change, so it needs the owner's word.

## What this item does not do

It does not add an enforcement point, and it does not make `manual` mean
anything new. The mode is still published, still readable, and still read by
nobody. **The difference is that the product now says that, rather than
leaving it as a question.**

The owner has not yet answered whether `workspace.autonomyMode` or
`autonomyPolicy.mode` is authoritative, whether the policy has a write path,
or whether a template may produce a live resource. Those are separate
questions and this item does not pre-empt them.
