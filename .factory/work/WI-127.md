## The finding

**WI-120 made the front page true. Nothing holds it true.** The identity sentence the
owner chose is in `README.md`'s third line and in `package.json`'s `description`, and
**no gate, test or script in this repository reads either of them.** The precedent for a
repo-root check is right there: `apps/server/src/__tests__/ownerPasswordExposure.test.ts:341`
reads `CONTRACTS.md`, `README.md` and `ARCHITECTURE.md` from the repository root, and
`apps/web/src/__tests__/forge-briefs.test.ts:73` resolves `repoRoot` and reads a
repository-root `README.md`.

**So a later commit can change the front page, or the manifest's description, and nothing
notices — the same defect class as WI-122, WI-123 and WI-116, one layer out.** The
contract's citations are held by gates that can see them drift; the front page's identity
sentence is held by nothing at all.

**What the check must hold, and what it must not.** WI-120's criterion 5 deliberately left
four in-repo places carrying the old tagline — `AGENTS.md:8`, `CONTRIBUTING.md:4`,
`docs/roadmap.md:17`, `.factory/work/WI-011.md:20` — and the item's decision was that
they are **not** silently fixed. **The check must not assert anything about those four.**
It holds the front page, and only the front page.

## The shape

**One new test file, in the server's suite, beside the precedent:**
`apps/server/src/__tests__/frontPage.test.ts`.

1. **`README.md`'s third line** must be exactly
   `**The environment one person's agents operate and extend.**`
2. **`package.json`'s `description`** must be exactly
   `Personal OS — the environment one person's agents operate and extend.`
3. **The two must agree with each other** — one sentence, two files, and the check must
   fail if either drifts away from the other.
4. **It holds itself to failing**: drifted copies — a README whose third line drifts, a
   manifest whose description drifts, the two that no longer agree — must each be caught
   **by name**, the way WI-122's pin catches its three citations.
5. **It reads only.** No file in the repository is edited by this work.
