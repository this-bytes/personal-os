## The problem

The README's licence section says **MIT** (`README.md:251-253`).

The owner's answer on 2026-10-21 was: the repository is **private for now**,
there is **no LICENSE file at this push**, and the licence is **deliberately
undecided** — not "no licence", undecided. A licence is a decision about what
other people may do with the work, and nobody made that decision. The README
asserts one anyway, and it is the first file a reader opens.

The same answer is why there is no LICENSE file in the repository: the absence
is the point, not an oversight, and the README is where that is said out loud.

## Notes

**Why the sentence is in the README and not only in the decision record.** The
owner asked for one honest sentence. A repository that is private now and
licensed later has to be able to say so at the door, and the README is the door.

**Why "undecided" and not "proprietary".** "Undecided" is the fact. Calling it
proprietary would make a decision in the owner's name, and this repository is
not theirs to close.
