## Problem

`CONTRACTS.md:630-644` publishes the waiting list's shape:

```ts
type WaitingKind = 'approval' | 'task';
type WaitingReason = 'pending' | 'review' | 'blocked';

interface WaitingItem {
  id: string; // unique across kinds, so the client can key the list.
  kind: WaitingKind;
  title: string;
  detail: string;
  reason: WaitingReason;
  workspaceId: string;
  conversationId: string | null;
  taskId: string | null;
  agentConnectionId: string | null;
}
```

The code emits a fourth reason. `apps/server/src/api/waiting.ts:17` declares:

```ts
export type WaitingReason = 'pending' | 'review' | 'blocked' | 'unknown';
```

and `apps/server/src/api/waiting.ts:85` assigns it straight from the task's
status, so a task whose outcome cannot be confirmed arrives at the client as
`reason: 'unknown'`.

**The published type is missing a member the code emits.** A client written
against `CONTRACTS.md` — a switch with three cases, a type that does not admit
`'unknown'` — is correct as written and wrong against the server. The owner
sees _"Check this"_ in the panel for such a task; the contract says that
outcome is spelled `blocked`, or `review`, or `pending`, and never `unknown`.

## Why this needs the owner

**This is a change to a published type.** `CONTRACTS.md` opens with its own
rules, and the first is:

> 1. A published contract is not changed without an explicit migration and
>    compatibility story.

Growing an enum that clients switch on is exactly that: a consumer that
exhaustively matches on `WaitingReason` and handles three cases is now
non-exhaustive. So the item needs the owner's nod and a migration note, the
same way [WI-016](../work/WI-016.md) and [WI-017](../work/WI-017.md) do — not
because the change is large, but because the contract's own rule says so.

Chief is not treating the owner's silence as consent here. The rule about
published types is the one rule in this factory that the owner reserved.

**The nod, and what it carries.** The owner approved this shape at 06:01 on
2026-10-21, as one of three published shapes. That approval carries the
