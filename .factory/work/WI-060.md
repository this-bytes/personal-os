# WI-060 — A turn's resolution lives on the turn's own row

**Owner:** Cog
**Verifier:** Probe
**State:** intake — funded and numbered, and **not dispatched**. It is a
declared shared table write with an owner, and it waits for capacity.
**Opened:** 2026-10-21 by the strategy session, from the domain map's declared
crossings
**Numbered:** 2026-10-21 — WI-046 through WI-061, taken by the session that owns
the number space.

## The gap it names

A turn is stored as an execution row, so resolving a turn — the owner's
decision about a turn whose outcome could not be confirmed — writes the
ledger's row from the Interaction domain. The `executions` module is
Interaction's, because a turn is Interaction's business; the `executions` table
is Work's, because the ledger owns the row.

**This one is a table write rather than an import**, which is why the manifest
keeps it in a separate list: proving that a module writes only its own tables
needs a data-flow analysis this repository does not have, and a rule nothing
verifies is a claim.

## Acceptance criteria

- [ ] **The turn's resolution lives on the turn's own row** — the fields that
      say how an unconfirmed turn ended are the turn's, and the ledger's
      execution row is not where they are smuggled in.
- [ ] **The domain map's table claims stop being crossed**, and the shared
      table write is removed from the manifest.
- [ ] **The owner's decision to close an unconfirmed turn still works**, and
      the test that covers it still passes untouched. WI-031 and WI-045 own
      that behaviour, and this item does not change it.
- [ ] **`docs/domains.md` is updated.**

## Not in scope

- **The `executions` table's ownership.** The ledger owns the execution row,
  and a turn and a task's execution are the same row. This item is about
  the fields that resolve a turn, not about the table.
- **The interaction model.** WI-055 is separate, and if it moves the turn's
  resolution onto its own row, this item is done by it rather than beside
  it.

## Notes

**This item and WI-055 may be the same work.** The published interaction model
gives the turn a capability view, a delegation tree and a `committed` state,
and a turn that owns its own resolution is a natural part of that. If WI-055
lands first, this item is closed by it and says so.
