## The problem

**A published document names a file that is not there, and nothing checks.**
`prototypes/briefs/03-execution-trace.md:20` cites `apps/web/src/api/events.ts`.
**There is no `apps/web/src/api/` directory in this repository** — the file the
brief means is `apps/web/src/state/events.tsx`, and the brief says so itself a
few lines later (`:20` names both). **A reader follows the first citation and
lands on nothing.**

**This is not a hypothetical class.** It is a defect that was found by reading
— Probe found it while verifying WI-024 — and a defect a reader finds is a
defect that a machine could have found.

**And the drift this factory has repaired all evening is a second, coarser
class that the check does not catch.** Two stale pointers in WI-022's entry
resolved to the **wrong claim** while pointing at a file and a line that exist
and are not blank. **So the check must not be described as "catches drifted
citations", because it does not.**
