## The reading, said out loud

**This item removes the `LICENSE` file on the reading that "there is no LICENSE
file at this push" means the repository carries no licence file.** That is the
owner's own words, twice: "no LICENSE yet" and "the licence is deliberately
undecided".

**The reading is stated here so that it can be contradicted.** If the owner
meant _"we are not adding a licence file now"_ and not _"the repository carries
no licence file"_, then this item's first criterion is wrong, and it goes back
to the owner. **Removing a stray grant is the safe direction** — the repository
is private, nothing is published, and a file that has been in the tree since
the first commit is a leftover of a decision the owner has since made
differently. It stays in the git history either way.

**This item does not decide the licence.** It removes a claim that the owner
said is not being made. What licence the repository will eventually carry is
the owner's question, and it is not this item's.
