**That is the old tagline, live, on the public repository — and it states three of the
things the product is not.** `docs/strategy.md:37` lists what the product is not: not a
chat home, not multi-user, not a workflow editor, not an inference engine, not a plugin

workflow editor.** WI-120 was opened because the same three exclusions stood in the
README's tagline; **the description was not in WI-120's scope — it is a setting, not a
commit — and it is still published.**

**And it is the first field a stranger meets.** GitHub renders the repository description
into the page's meta description and into the social preview card, so a search result or a
shared link shows the sentence the owner replaced. **The files were corrected; the field the
owner sees first was not.**

**One field, one sentence.** The description becomes:

```
Personal OS — the environment one person's agents operate and extend.
```

**That is `package.json`'s `description`, byte for byte** — the same string the manifest
carries and the same identity sentence the README's third line carries. **One sentence, in
three places, so a check can hold them together.**

**Who makes it:** the owner, in the repository's Settings, or **the lead, with the owner's
word**, through the same credential the pushes already use. **Nothing outside the
