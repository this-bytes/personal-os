But "behind main" does not mean "worthless". `wi/071-accent-one-meaning`
carries **twelve substantive commits** — the Forge accent system, including
`apps/web/src/__tests__/accentGuard.test.tsx`, a 348-line guard that enforces
"one accent, one meaning". That is real product work that exists nowhere else.

## What this item does

Triage every stranded branch, and salvage what is worth keeping onto fresh
branches based on current `main`.

## The rules

1. **Never merge a stale branch into `main` as-is.** The deletion figures above
   are why. Merge or rebase onto current `main` first, then take the content.
2. **Never force-push, and never delete a branch.** Branches are closed by
   marking them superseded in their own item file, not by deleting them.
3. **One salvage at a time**, each on its own fresh branch off current `main`,
   each verified with the gates that apply to it.
4. **A branch whose content is already on `main` is superseded.** Record that
   and move on. Do not spend a cycle proving it twice.

## Priority order

1. **`wi/071-accent-one-meaning`** — twelve substantive commits of the Forge
   accent direction, stranded. This is Phase 4 of the 48-hour build and the
   largest block of real product work in the stranded set.
2. **`wi/044-vendored-sources`** — the owner's own borrow rule, half-landed.
   The inventory is done; the gate that proves it can fail is Probe's half and
   is not written.
3. **`wi/038-borrow-rule-gate`** — the gate wiring that goes with it.
4. Everything else — triage only. Most of it is superseded.

## Acceptance criteria

- [ ] Every one of the thirteen branches has a verdict: **salvage**, **superseded**
      or **still in flight**, with the reason and the measurement behind it.
- [ ] The salvaged content from `wi/071-accent-one-meaning` is on a fresh branch
      off current `main`, and the Forge accent system is intact — including
      `accentGuard.test.tsx`.
- [ ] No branch is deleted and nothing is force-pushed.
- [ ] Every salvage is verified: `npm run typecheck`, `npm run test`,
      `npm run format:check`, `npm run build`, and — because the web client
      changed — `npm run test:e2e` and `npm run verify:bundle`.
- [ ] `main` is not touched by this item.

## Gates

`npm run typecheck` · `npm run test` · `npm run format:check` · `npm run build` ·
`npm run test:e2e` · `npm run verify:bundle`

## Deliverable

The verdict table for all thirteen branches, and for each salvage: the new
branch name, the commits carried over, and the gate output verbatim.
