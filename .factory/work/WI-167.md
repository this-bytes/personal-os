## Problem

The repo now carries a Codex adapter (`packages/agent-adapters/src/codex.ts`,
the owner's branch `wi/157-codex-runtime`) and a fixture
(`apps/web/e2e/fixtures/fake-codex-agent.mjs` with
`apps/web/e2e/codex-runtime.spec.ts`). **A fixture is a test, not evidence.**
`.factory/DIRECTIVE.md` §2 is explicit: "The Echo agent, `fake-codex-agent.mjs`
fixtures and protocol replays are tests, not evidence."

R1 passes when the owner completes real work in the web chat against a **real,
installed runtime**, once for Codex, with streaming output, tool activity
trace, file/image artifacts, Markdown/code, history restore, stop/cancel, and
an in-conversation permission question answered without losing the turn.

**Outcome:** that demonstration exists, as a transcript naming the runtime
version, the commands run, the output produced and the limits that remained.

## Scope and compatibility

- **Owned paths:** the demonstration itself, against a real installed Codex
  runtime. Where the demonstration exposes a gap in the adapter's real-runtime
  path, that gap is the slice's work; the adapter is in scope only to the
  extent the demonstration needs it to be usable.
- **Boundaries:** the shipped fixtures and e2e spec stay as they are. The
  demonstration is **not** a test, and does not live in the test suite.
- **Compatibility:** nothing about the shipped behaviour changes for the
  demonstration; the transcript is the deliverable.
- **Data migration:** none.

## Acceptance criteria

- [ ] Streaming output, tool activity trace, file/image artifacts and
      Markdown/code are demonstrated.
- [ ] History restore is demonstrated: the browser is closed and reopened and
      the same conversation continues.
- [ ] Stop/cancel is demonstrated with a confirmed state, or the uncertain
      remote outcome is explained.
- [ ] An in-conversation permission question is answered **without losing the
      turn**.
- [ ] The evidence names the runtime version, the commands run, the output
      produced, and the limits that remained.
- [ ] **A fixture run is not offered as the proof.** A demonstration
      substitute fails review.
- [ ] Applicable gates pass on the delivered revision.
- [ ] Independent review findings are resolved.

## Not in scope

- Echo, fixtures and protocol replays as evidence of anything.
- The OpenCode demonstration — its own item.
- The parity work (`docs/spec/s1-approval-execution-parity.md`) and anything
  `docs/spec/p0-feature-audit.md` ranks after the R1 rows.

## Evidence

- The demonstration transcript itself, plus revision, the commands actually run
  and their results, runtime versions, inspectable output, limitations and the
  reviewer's verdict. A state label is a report, not proof.
