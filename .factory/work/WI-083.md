# WI-083 — The documented gaps that the code has already closed

**Owner:** Wren
**Verifier:** Probe
**State:** implement — dispatched 2026-10-21 as part of the 48-hour build.
**Numbered:** 2026-10-21 by the session that owns the number space for this push.

## The problem

The documentation is **ahead of the code in some places and behind it in
others**, and the factory has been paying for both.

The clearest instance of "behind": `ARCHITECTURE.md` §9 still says

> **ACP sessions are not resumed.** … The published contract has already moved:
> `CONTRACTS.md` says a turn re-enters the same session when the adapter reports
> `persistentSessions` (WI-007). **The code has not caught up.**

It has caught up. `packages/agent-adapters/src/acp.ts:213` implements
`resumeSession`, `apps/worker/src/executor.ts:375` calls it, and both
`apps/server/src/__tests__/approval-resume.test.ts` and
`apps/worker/src/__tests__/approval-resume.test.ts` cover it. `SECURITY.md:55`
carries the same stale claim.

**A stale "gap" in the docs is an invitation to rebuild something that
already exists.** That is how a factory spends a day of model budget and
produces a commit that changes nothing — which is exactly what 380 of the
437 commits in this repository did.

## What this item does

Sweep every published document for a claim that the code has already closed,
and correct the claim.

The documents in scope: `ARCHITECTURE.md`, `PRODUCT.md`, `CONTRACTS.md`,
`SECURITY.md`, `README.md`, `docs/strategy.md`, `docs/decisions/**`.

## Acceptance criteria

- [ ] Every "not implemented yet", "the code has not caught up", "not yet
      enforced" or equivalent claim in the documents above is checked against
      the code, and each one is either corrected or confirmed still true.
- [ ] A claim is only corrected when the code **and a test** support the
      correction. A claim corrected on the strength of a reading is worse than
      the stale claim.
- [ ] Where a claim is confirmed still true, the item says so explicitly — a
      gap that is real stays a gap, and this item must not quietly delete one.
- [ ] `CONTRACTS.md` is not touched. It is a published contract; a change to
      it needs a migration plan and the owner's nod. If a contract entry is
      stale, report it instead of editing it.
- [ ] `npm run format:check` passes.

## Gate

`npm run format:check` · `npm run test`

## Deliverable

The report lists each claim, what the code says about it, and what was
changed — with the file and line for both. A claim nobody checked is not
listed as checked.
