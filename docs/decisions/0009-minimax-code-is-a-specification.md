# 9. Learn interaction patterns without embedding another product

**Status:** accepted; clarified by the 2026-10-22 recovery.

Use MiniMax Bot as inspiration for configurable agents, group mentions, delegation,
continuing work and visible results. Implement Personal OS's own domain contracts;
keep runtime reasoning and native execution in the external harness.

Prefer maintained protocol SDKs and established libraries. Independent product
ownership does not require handwritten protocol clients or a ban on useful SDKs.
Check the exact source/version and license before copying code or adding a library.
Public catalog/CLI behavior does not prove the private desktop host's internals.

[The adapter research](../adapters.md) records primary sources and candidate
integration surfaces. The earlier source-reading narrative remains in Git at
507708b; it is not an active feature list or implementation-status claim.
