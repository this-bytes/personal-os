# The pinned Codex App Server protocol

The schema the `codex-app-server` adapter is written against, for **Codex 0.163.0**.

## How it was produced

```
codex app-server generate-json-schema --out <DIR>
npx tsx scripts/pin-codex-protocol.ts --from <DIR> --version 0.163.0
```

The runtime that produced it was `codex-cli 0.163.0`.

## What this is, and what it is not

**This is a subset of the generated schema, not the whole of it.** The full
bundle is 318 files and 3629800 bytes, and most of it is
not the route this repository implements. What is committed here is the
schema of the methods and notifications the adapter actually uses — the
calls it makes and the notifications it reads — and, for each of those, the
definitions it depends on.

**Nothing is paraphrased.** Every definition is the generated bytes,
unchanged; only the definitions that nothing in the subset reaches are
dropped. `scripts/pin-codex-protocol.ts` is the tool that does it, and it
works on the raw text rather than on a parsed value, so a number written as
`0.0` stays `0.0`.

**A pinned subset that says what it is beats a pinned whole that claims to
be complete.** This record is part of the artifact for that reason: a reader
who finds a method missing here learns that the route does not use it, not
that the runtime does not have it.

The three files at the end are the protocol's **method tables**: every
method the App Server knows, with its parameters. Each entry of a table is
one method, so the entries this route does not use are dropped and the rest
are kept as they were generated. The gate reads these tables, which is how it
knows that every method the adapter sends is one the protocol defines.

| approvals | `ExecCommandApproval*.json`, `ApplyPatchApproval*.json`, `CommandExecutionRequestApproval*.json`, `FileChangeRequestApproval*.json`, `PermissionsRequestApproval*.json` |

## When the runtime changes

A new runtime version is a new directory, and the adapter is read against
the new one before the old one is dropped. `docs/adapters.md` names the
version every row was verified against, and that row moves with it.
